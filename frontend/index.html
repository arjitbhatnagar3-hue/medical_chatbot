Why MediBot is different

Grounded in your book

Answers come from your own medical text via semantic search — not the model's training data.

Cited sources

Every answer links back to the document and page number, so you can verify the claim.

Safe & transparent

If the answer isn't in the book, it says so — plus a clear "not medical advice" disclaimer.

How it works

A simple Retrieval-Augmented Generation pipeline running on FastAPI + FAISS.

1

You ask

Your question is turned into a vector and matched against the book's indexed passages.

2

It retrieves

The most relevant chunks are pulled from a FAISS vector store built from your PDF.

3

It answers

An LLM writes a grounded response using that context, with page citations.

MediBot is a demo project and is not a substitute for professional medical advice. Always consult a qualified healthcare provider.

Built with Python · FastAPI · FAISS · LangChain · Hugging Face · Docker
